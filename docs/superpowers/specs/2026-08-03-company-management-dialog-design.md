# 회사 등록 이력 관리 팝업 설계

## 목표

설정의 등록 회사 현황에서 각 회사의 조치(톱니) 버튼으로 현재 정보를 확인하고, 수정하거나 완전히 삭제할 수 있게 한다.

## 사용자 흐름

1. 사용자가 회사 행의 톱니 버튼을 누른다.
2. 회사 관리 팝업에 선택한 회사의 현재 정보가 채워진다.
3. 사용자는 회사 코드, 회사명, 업종, 기능통화, 표준시간대, 회계연도 시작월, 월 마감일을 수정하고 저장할 수 있다.
4. 팝업 하단의 빨간 `회사 삭제` 버튼을 누르면 별도 확인창이 표시된다.
5. 확인창에서 삭제를 확정하면 회사와 이 회사에 속한 애플리케이션 저장 이력이 완전히 삭제되고, 목록 및 요약 수치가 즉시 갱신된다.

## API와 권한

- `PATCH /api/v1/companies/{company_id}`: 관리자만 수정 가능하다.
- `DELETE /api/v1/companies/{company_id}`: 관리자만 완전 삭제 가능하다.
- 존재하지 않는 회사는 404를 반환한다.
- 삭제 전에는 해당 회사에 속한 저장 컬렉션을 함께 제거해 고아 데이터를 남기지 않는다.
- 수정과 삭제는 감사 이력에 각각 `COMPANY_UPDATED`, `COMPANY_DELETED`를 남긴다.

## UI와 오류 처리

- 톱니 아이콘은 접근 가능한 버튼으로 구현한다.
- 저장 중에는 중복 제출을 막고, 성공하면 팝업을 닫고 목록을 새로 고친다.
- 삭제는 확인창의 명시적인 확정 전에는 실행하지 않는다.
- API 오류는 팝업 안의 안내 메시지로 표시하고, 입력 내용은 유지한다.

## 검증

- API 테스트로 수정, 삭제, 존재하지 않는 회사의 오류 및 회사 관련 데이터 삭제를 검증한다.
- 프론트엔드 생산 빌드로 타입과 번들 생성을 검증한다.
