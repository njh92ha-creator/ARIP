# 리스크 검토 분류 및 유사 사례 추천 설계

## 목표

리스크 상세에서 Check, Pending, Pass를 선택한다. Pass는 리스크 관리와 리스크 검토 목록에서 숨기고, Check와 Pending만 리스크 검토 화면에서 관리한다.

## 데이터 원칙

선택값은 기존 `RiskMemoryEntry`에 `REVIEW_DECISION` 이력으로 저장한다. 기존 `Risk` 데이터 모델을 변경하지 않아 저장된 리스크와 호환성을 유지한다. 이력이 없는 리스크의 화면상 기본값은 Check다.

## 목록과 검토 화면

- `/risks`는 Pass를 제외한다.
- `/risk-reviews`는 Check와 Pending 리스크만 반환한다.
- 기존 `/events` 경로의 화면 표기는 `리스크 검토`로 바꾸고 `/risk-reviews`를 사용한다.

## 추천

사용자가 명시적으로 저장한 `REVIEW_DECISION` 이력만 학습 표본으로 사용한다. 같은 사건 유형, 계정코드, 계정명, 적요 토큰이 겹치는 과거 리스크에 가중치를 주어 다수 선택을 추천한다. 표본이 없거나 동점이면 추천하지 않는다. 이는 외부 모델이나 임의 판단이 아닌 사례 기반 학습이다.

## Pass 처리

Pass는 DB 이력으로 남는다. 리스크 관리 및 리스크 검토 API 목록에서만 제외하며, 데이터는 삭제하지 않는다.
