# 현재 적용 중요성 기준 설계

## 목표

회사별로 현재 적용 중인 감사 중요성 기준 한 건을 저장하고, 저장 후 회사 및 회계연도 정보와 함께 확인한다.

## 동작

- 회사마다 중요성 기준은 한 건만 유지한다. 저장은 생성 또는 갱신(upsert)으로 처리한다.
- 감사 중요성 탭을 열면 선택 회사의 기존 기준을 조회해 입력 항목에 채운다.
- 검토 후 저장은 벤치마크, 전체·수행·사소한 금액, 적용 시작일을 저장하고 승인 상태로 둔다.
- 저장 성공 후 서버의 값을 다시 조회해 결과 영역에 회사명, 회사 코드, 회계연도 시작월과 중요성 기준을 표시한다.
- 저장 실패 시 화면에 오류를 표시한다.
- 임시 저장 버튼, 정적 버전 이력, 저장되지 않는 종료일 및 정성적 고려사항 입력은 제거한다.

## API

- `GET /settings/materiality?company_id={uuid}`: 회사의 현재 기준을 반환한다. 없으면 `null`을 반환한다.
- `PUT /settings/materiality/{company_id}`: 현재 기준을 생성 또는 갱신하고 승인 상태의 결과를 반환한다.

## 검증

- 같은 회사에 두 번 저장해도 중요성 기준 레코드는 한 건만 남는다.
- 저장 뒤 조회 결과와 화면의 결과 영역이 일치한다.
- 다른 회사의 기준은 현재 회사 화면에 표시되지 않는다.
